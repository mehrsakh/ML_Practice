# ML-Practice

This repository contains a small practice project using **Python, NumPy, and pandas**.  
The purpose is to learn the basics of creating and manipulating **DataFrames** and exporting them to **Excel**.

---

Requirements
Make sure the following Python packages are installed:

bash
Copy code
pip install numpy pandas openpyxl
How to run
Clone the repository:


git clone https://github.com/Mehrsakh/ML_Practice.git
Open Jupyter Notebook:


cd ML-Practice
jupyter notebook
Open the notebook and run the cells to see the DataFrame and generate the Excel file.
